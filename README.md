# Análise de títulos da Netflix

Este projeto, ainda em desenvolvimento, explora uma base de filmes e séries da Netflix. A análise aborda a distribuição dos tipos de conteúdo e dos anos de lançamento, além da qualidade dos dados.

O projeto foi criado por mim para praticar pandas, limpeza de dados, visualização e interpretação dos resultados.

## Arquivos

- `guia.ipynb`: versão mais recente do estudo, em andamento;
- `analise.ipynb`: exploração inicial feita durante o estudo;
- `netflix_titles.csv`: base utilizada nos notebooks;
- `requirements.txt`: bibliotecas necessárias para executar o projeto.

Para continuar o estudo, abra esta pasta no VS Code e execute `guia.ipynb`.
